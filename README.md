# Lampblack Forno assets

Public brand assets for **Lampblack Forno**, a fictional coal-oven pizza shop in Ghent, Norfolk. They exist so a BuoyForms draft can load the logo over HTTPS.

- `lampblack-forno-logo.svg` — wordmark and oven-door monogram (preferred)
- `lampblack-forno-logo.png` — raster fallback
- `lampblack-forno-mark.svg` — monogram only

The shop is invented. These files are not a real restaurant identity.
